Schibsted Grotesk has no \u025B, \u0254, \u0256, \u0263 or \u028B. This post is how we found the gap, how to check any font for Twi, Ga and Ewe letters, and our plan to close it.

### How we found the gap

We checked every letter our customers write. Names and words in Twi, Ga and Ewe need letters many typefaces do not have: \u025B \u0190 \u0254 \u0186 \u0256 \u0263 \u028B. Our text typeface has none of them. It does have \u014B and the usual accents. A name set in a face that cannot draw its letters is not set at all, so we say so plainly.

### How to check any font

Set the letters themselves, at text size and at headline size: \u025B \u0190 \u0254 \u0186 \u0256 \u0263 \u028B \u014B. Then set a real name and a real sentence that use them. If a letter arrives in a different face, thinner, or on a different baseline, the font does not have it, whatever its character map claims. We check every letter in your name and your words before we choose type.

### What we do now, and what we plan

For now, a second typeface sets those letters by unicode range, so the page does not break. We plan to have a type designer draw the missing letters into a licensed version of the typeface, which its licence allows. Until then, we do not say the gap is closed. The status is planned, and the letters page keeps it in the open.

### What we gave up

We gave up pretending one family already does everything. One family, and an honest gap, is the true description. Closing the gap is drawn work, and drawn work takes the time it takes.
