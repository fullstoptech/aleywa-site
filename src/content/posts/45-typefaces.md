We tested our studio name in 45 typefaces. Several read as default faces and none carried the idea, so we drew the wordmark. This post is what we tested and why we stopped testing.

### What we set, and how we judged it

We set the same word, aleywa, in each face at the same size, and judged it on the idea: round letters, one square stop. A face passed only if the letters felt round and hand-cut next to a square, and if the word still read at the size of a browser tab. Most faces failed on the first look. A few held for a day, then read as the face, not as our name.

### Why none carried the idea

Several read as default faces: well drawn, and already somebody else's. The rest split the idea. Round faces softened the stop. Square faces hardened the letters. None gave us round letters that end, without apology, in one square. That tension is the brand, so borrowing a face meant giving up the idea to keep the letters.

### Drawing it instead

So we drew the wordmark: lower case, round letters, flat-ended strokes, and the square stop. Drawing it let us set the space between letters by measuring, draw a separate small version for tiny sizes, and write the rules so anyone on a team can use it. The book of rules runs to more than fifty pages.

### What we gave up

We gave up a ready-made typeface, and a cut on the e. A ready-made face would have been faster. It would also have been someone else's drawing, carrying someone else's idea.
